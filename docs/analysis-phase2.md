# 节目分析第二期

第二期包含新闻/话题章节、原文与时间点关联、点击回看、转写检索和字幕导出，
同时落地并行转码、人工校正和断流成果保留，不新增常驻服务。

| 项目 | 用户可见行为 |
| --- | --- |
| ⑦ 转码与 AI 解耦 | 录像采集结束后即可转码，ASR/LLM 可同时继续。仍有读者或尚待 ASR 的原 TS 延后清理。 |
| ⑧ 摘要可追溯 | 要点附原文摘录及媒体时间，点击回看；原文可人工校正，只重算受影响笔记并汇总新摘要。 |
| ⑨ 保留部分成果 | 中断前可用片段独立保存，展示估算缺失区间；已完成的实时草稿保留，可查看和录后补转写。实际录制结果反馈源健康数据。 |

基于直播实际内容触发订阅提醒属于后续选配，不在本期。

## 转码与文件保护

`file_path` 指向当前可播放版本，`asr_source_path` 固定本次转写的媒体来源。
转码发布 MP4 不会改变正在运行的 ASR 已领取路径。`media_readers` 为 ASR、转码、
播放准备和下载提供跨进程领取与心跳；清理前先封闭新读取，再删除无人读取的文件。
原文件在 ASR 到终态后清理，无需继续等待 LLM。配置为保留原片、或含断流片段时保留原文件。

临时失联的读取租约会过期，仍在工作的读者定期续租。升级必须等待旧版本读者完成，
避免旧进程尚未采用新保护协议。不要通过手工删 TS 的方式验证此功能。

## 要点与原文

模型接收带段落 ID 的文字，返回要点及引用 ID、逐字摘录。
服务端验证 ID 和摘录；媒体时间与片段由服务端补齐，不采信模型生成的时间。
验证通过不等于语义事实核验，用户仍应结合原文与录像判断。
无有效引用的要点显示“未定位原文”，不会伪造可点击的时间点。

旧摘要不会自动重跑并消耗 LLM。录制详情中的“重新生成可追溯摘要”可按需处理旧录像。
模型支持原有 JSON 摘要调用，不依赖额外检索服务。

## 人工校正与重新生成

录制详情 → 转写时间轴 / 人工校正：

1. 录制、转写和当前摘要处理完成后才能校正，避免后台任务覆盖人工文字。
2. 每段可回看、修改文字；保留首次识别原文、修订版本与审计记录，不修改录像。
3. 保存使用乐观版本检查。另一页面已改动时返回冲突，刷新原文后再操作。
4. 内容摘要笔记按原文内容签名缓存，未变更分段继续复用；受影响分段与终版重新生成。
5. 旧摘要标记过期，新版完成前不作为当前正式结果展示。
6. 默认不重新发送通知；保存时明确勾选重新推送才允许新版投递。

投递记录按摘要 generation 区分，同版本重试不重发已成功的渠道。
外部通知发送与数据库确认仍无法形成恰好一次事务。

## 话题导航、检索与字幕

摘要页“新闻 / 话题章节”使用已验证原文引用的起点作为导航，点击跳到对应媒体位置。
标题来自摘要要点；这些起点是内容定位参考，并非模型判定的精确节目编辑边界。
没有有效引用的内容不生成猜测时间；旧摘要可按需重新生成。

“转写时间轴 / 人工校正”支持文字检索，按当前校正后的文字匹配，结果可分页和回看。
检索按字面文本匹配，不解释正则，也不要求启动搜索组件。

完整录像可导出 UTF-8 SRT、WebVTT；时间使用媒体内时间，文字使用当前修订版。
断流录像分别播放，因此字幕也须按片段导出，避免把总时间轴错误套到单个片段。
未完成的实时草稿不能作为正式字幕导出。

## 断流与部分成果

默认保留至少 5 秒且大于 256 KiB 的可读片段，可通过
`RECORDING_PARTIAL_MIN_SECONDS`、`RECORDING_PARTIAL_MIN_BYTES` 调整。
在 FFmpeg 回退 PyAV、重试换源和最终放弃时，先保留已经写好的可读媒体。
新任务记录临时文件位置，失去心跳的任务在恢复领取前尝试收回已写片段。

不同来源可能有延迟或重复，片段分别播放和下载，不强行拼接成看似连续的视频。
每段包含原始音轨，不需要为了“保留音频”再完整复制一份音频文件。
最终无法录全时，仍对保留片段转写和总结，正式摘要明确标注只覆盖保留内容。

缺失区间由采集时间、媒体时长估算，不能据此认定不同源的画面已经精确对齐。
在录制详情查看片段、估算缺口和中断前已完成的转写草稿。

源页面增加最近 20 次实际录制的稳定性数据，与短分片带宽探测分别展示。
同一领取尝试只计一次反馈，反馈不改用户锁定源的地址或优先级。

## 页面验收

| 场景 | 通过标准 |
| --- | --- |
| 转码与 AI 并行 | 采集结束、AI 未完成时转码可工作；最终录像、转写、摘要均可正常使用。 |
| 摘要回看 | 点击要点的原文时间，打开对应录像或断流片段，并跳到该段媒体位置。 |
| 话题章节 | 章节标题和时间可见，点击进入相应录像位置，无引用时不伪造章节。 |
| 原文检索 | 输入原文关键词，只显示匹配段落，可回看；不存在的词返回空结果。 |
| 字幕导出 | SRT/WebVTT 使用当前文字，时间正确；断流按片段导出并使用片段内时间。 |
| 文字校正 | 保存后版本增加、原文保留，摘要更新为新版；默认没有重复通知。 |
| 并发校正 | 两页面编辑同一旧版本，后保存者收到版本冲突。 |
| 历史摘要 | 按需重新生成后具有有效原文依据，未定位的要点有明确提示。 |
| 断流保留 | 有可用内容时能查看、播放和下载分段，摘要带不完整标记，缺口有提示。 |
| 源稳定性 | 有实际录制反馈的源可见最近尝试数、稳定性，锁定及优先级保持用户设置。 |

断流注入与文件删除竞争应在隔离环境验收，避免人为影响生产节目。

## 部署与回退

本期定向更新 recorder、encoder、ASR、background 和 web；沿用媒体与 ASR 镜像，
不为这些功能增加数据库或队列容器。部署前排空五个目标服务并保留旧镜像及配置。
完整启动后再解除维护暂停，确保旧读取进程已经退出后才启用提前清理。

新增数据均为附加字段和集合。回退会失去新页面入口，但已保留的片段和修订记录
不会被主动删除；回退工具不能恢复已经按保留策略删除的媒体。
