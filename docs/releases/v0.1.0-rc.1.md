# IPTVPilot v0.1.0-rc.1

这是 IPTVPilot 的首个公开候选版本，面向可信家庭内网中的 `linux/amd64` 主机或 NAS。候选版本用于收集首次部署、不同 NAS 环境和真实日常使用中的反馈，接口与部署配置在正式版前仍可能调整。

## 主要能力

- 统一管理频道和多条直播候选线路，并在浏览器中播放 HLS 直播。
- 导入 XMLTV 节目单，按关键词或频道时间创建录制订阅。
- 使用 FFmpeg 录制节目，并提供浏览器播放和下载。
- 可选启用语音转写、AI 节目摘要、向量搜索和邮件通知。
- 提供 MongoDB 备份、过期录像清理和直播线路质量刷新任务。
- 提供首次直播源配置指南，以及自建频道清单和授权 M3U/TXT 订阅的批量导入助手。

## 安装

克隆候选版本并创建配置：

```bash
git clone --branch v0.1.0-rc.1 https://github.com/karlazx/iptv-pilot.git
cd iptv-pilot
cp .env.example .env
chmod 600 .env
```

如需使用 GHCR 预构建镜像，在 `.env` 中设置：

```dotenv
IPTV_PILOT_IMAGE=ghcr.io/karlazx/iptv-pilot
APP_TAG=0.1.0-rc.1
```

完成密码、存储路径和可选 AI 配置后启动：

```bash
docker compose config --quiet
docker compose up -d
docker compose ps
```

全新部署不会包含任何直播源。打开管理台手动添加首个自有或授权频道，或按照[首次添加直播源](https://github.com/karlazx/iptv-pilot/blob/v0.1.0-rc.1/docs/live-sources.md)批量导入。

## 使用边界与已知限制

- 默认部署只适用于可信内网，不要把管理台、iptv-api、MongoDB 或 MongoDB Search 直接暴露到公网。
- 只支持 `linux/amd64`；ARM64 尚未正式验证。
- 可选直播规范化服务依赖 Intel VAAPI 和 `/dev/dri/renderD128`。
- 默认 AI 后端为 mock，真实转写、摘要和向量搜索需要额外依赖、模型或服务凭据。
- 项目不提供任何可工作的频道、IPTV 订阅或第三方 EPG 地址；用户必须确保内容来源合法、可信且已获授权。

提交问题时，请删除直播 URL、访问令牌、局域网地址、邮箱、录像和日志中的私人信息。安全问题请使用 GitHub 私密漏洞报告。
