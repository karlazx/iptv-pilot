# IPTVPilot v0.1.0-rc.18

无节目单频道可通过“独立时段”订阅直接录制，配置星期、当地时区、时刻和时长，并预览未来 7 天。
旧 EPG 时刻匹配保持兼容；独立时段支持跨午夜，夏令时不存在时刻跳过、重复时刻只执行一次。

录像、摘要、订阅、频道、直播源、收藏和推送事件提供分页和服务端检索。
活跃录像仅批量刷新当前页状态，收藏按页关联查询；旧 API 数组响应继续兼容。

采集前可裁剪相邻订阅重叠缓冲，不能裁剪节目内容。正在运行的采集不强行中断，真实重叠会显示冲突。
计划迟到与节目头部缺失分别展示，历史指标不冒充精确缺失时间。
停用订阅在实际采集前再次检查；独立时段不会被误标为 EPG 时间存疑。

## 升级与使用

定向更新 recorder、background、web；只需媒体镜像，不要求更新 ASR、encoder、MongoDB 或 iptv-api。
升级前排空目标服务，保留旧镜像及配置作为回退。新增分页索引在 web 启动时创建。
