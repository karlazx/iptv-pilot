# IPTVPilot v0.1.0-rc.14

本版本补充 rc.13 部署验收中发现的队列告警与后台日志问题。

- 队列中的未来重试时间属于正常退避，不作为停滞；等待超时从实际可领取时刻计算。
- API 增加 `retrying` 和 `oldest_ready_at`，界面区分退避任务。
- 紧凑后台将 httpx 请求日志设为 WARNING，与原独立质量 worker 一致，避免记录完整签名 URL。
- 修正 EPG 刷新周期下限的单位。

相对 rc.13，本次可只更新 web 和 background，无需重启 recorder、encoder 或 asr。
若部署指定了自定义 `FFMPEG_BIN`，迁移媒体镜像时请确认该路径存在；使用内置二进制应设为 `auto`。
