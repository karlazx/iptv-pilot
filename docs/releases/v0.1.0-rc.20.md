# IPTVPilot v0.1.0-rc.20

摘要调用新增可选的 `LLM_REASONING_EFFORT`，供支持该参数的模型控制推理强度。留空时省略请求参数，保持现有接口行为；各服务商和模型支持的取值不同，使用前应核对其文档。

实时笔记与正式摘要共用配置。重新生成时，分段笔记缓存会区分推理强度；未配置该项时继续复用原有缓存。

修改 `.env` 后只需定向更新 compact 模式的 `background` 或 split 模式的 `llm`，无需更新 ASR、录制器、转码器或数据库。沿用当前 Compose 文件组合与服务镜像清单。已耗尽重试的任务须在录像详情重新生成摘要，默认不再次推送。
