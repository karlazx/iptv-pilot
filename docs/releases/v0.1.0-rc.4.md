# IPTVPilot v0.1.0-rc.4

本版本引入锁定的多源管理：频道可以配置一个不会被自动替换的首选源和多条备用源。

## 主要变化

- 每个频道拥有有序的源列表，其中一条为首选源。首选源默认锁定，M3U 同步、质量刷新和直播规范化都**不会**修改它的地址、优先级或锁定状态。
- 首选源不可用时按优先级自动回退到备用源；首选恢复后，下一次播放自动切回。
- 录制定时任务在开始时固定源，整段录像和重试都不会中途换源。
- 支持手动添加自定义 URL、导入备用 M3U（先预览再写入）、按 `tvg-id` / 名称 / 归一化名称匹配频道。
- 管理台直播源页面按频道分组，显示锁定/首选/回退状态，可临时切换、设为首选、启停、测试和导入。
- 新增迁移脚本 `scripts/migrate_sources.py`，把现有 `m3u_url` 锁定为首选，升级后播放行为不变。

## 升级

```bash
docker compose pull
docker compose up -d
docker compose run --rm --no-deps asr python -m scripts.migrate_sources --dry-run
docker compose run --rm --no-deps asr python -m scripts.migrate_sources --apply
```

如果历史同步曾覆盖掉桥接源，可先用 `scripts/restore_bridge_sources.py --dry-run` 确认，再 `--apply` 恢复。

## 已知限制

- 录制器仍按单条任务顺序处理；并发录制将在后续迭代解决。
- 默认仍是可信内网部署，不要直接暴露管理台、iptv-api、MongoDB 或 MongoDB Search。
