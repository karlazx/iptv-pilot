# IPTVPilot v0.1.0-rc.15

ASR 新增可选 Intel GPU 加速及自动 CPU 回退，沿用有界分段、检查点、心跳和任务预算。

配置 `ASR_BACKEND=auto`，使用 `ASR_DEVICE=cpu|gpu|auto` 选择设备。
GPU 不支持、缺少运行库/驱动、本地转换模型不匹配或推理抛出异常时，使用 faster-whisper CPU；
推理异常会在 CPU 重新处理当前窗口。录制任务和转录记录实际运行路径，恢复检查点时也保留来源。

Intel 使用可选 `-asr-intel` 镜像及 `docker-compose.asr-intel.yml`。只更新 ASR 服务即可，
普通 `-ai` 及媒体镜像不携带 OpenVINO。新增的是镜像变体，不是额外常驻服务。
宿主机没有 DRM 设备时，覆盖配置仍允许 ASR 容器启动并回退 CPU。

100 条带人工参考的普通话样本共 19.4 分钟，CPU/GPU CER 分别为 11.83%/12.05%；
GPU 耗时从约 316 秒降至 162 秒，CPU 运算时间减少约 86%，两组时间戳检查无异常。
另有静音及无 GPU 实际转写验证。评测正文和个人部署配置只保存在部署环境。
完整 118 分钟录像在 3 GiB 限制内完成 24 个 GPU 窗口，约耗时 15 分钟，无 OOM 或回退；
GPU 推理异常后由真实 CPU 模型接手当前音频的验证通过。129 项回归测试通过。

配置、模型准备和评测范围见 [ASR 加速说明](../asr-acceleration.md)。
