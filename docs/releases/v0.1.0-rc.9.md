# IPTVPilot v0.1.0-rc.9

本版本修复 EPG 多源配置只生效第一个的问题，并增加 EPG 过期检测。

## 主要变化

- **EPG 多源合并**：此前 `EPG_URLS` 里只有第一个成功的源会被读取，后面的源永远不会生效。现在会抓取全部源并合并，单个源失败只跳过它自己。
- **优先级**：重复的 `(频道, 开始时间)` 以配置顺序靠前的源为准。
- **可观测性**：每个源的频道/节目数会单独写日志；`/api/system/status` 新增 `epg_upcoming_24h`、`epg_latest_start`、`epg_status` 三个字段。
- **过期告警**：一次刷新后若未来 24 小时没有任何节目，会记录 error 日志，便于第一时间发现源失效。

## 升级

```bash
docker compose pull
docker compose up -d
```

升级后检查：

```bash
curl -s http://127.0.0.1:5190/api/system/status | python3 -m json.tool | grep epg_
docker compose logs --tail 30 epg-engine | grep "EPG source ingested"
```

每个源的收录数量会分别列出，若某个源显示 `programmes=0` 或数值明显缩小，说明该源已失效。

## 说明

本版本只修复取值与合并逻辑，不改变上游 EPG 数据本身。若所有配置源都停止更新，`epg_status` 会显示 `stale`，此时需要更换 EPG 提供方。
