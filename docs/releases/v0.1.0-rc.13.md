# IPTVPilot v0.1.0-rc.13

本版本按三批优化任务恢复、镜像与升级方式，以及紧凑部署。

- ASR 默认按 5 分钟流式解码并保存转写检查点；重试复用已完成分段。
  心跳保护长任务，领取即消耗预算，避免 OOM 后无限重试。
- 系统设置页增加队列状态和进度异常提示。
- recorder/encoder/web 使用含 FFmpeg、PyAV 的媒体镜像，只有 ASR 需要 Whisper 镜像。
- 默认 compact 模式通过一个 background 进程运行轻量任务；split 模式保留独立 worker。
- MongoDB Search、第三方 iptv-api、硬件规范化按需启用。
- 提供定向升级和本地回退备份工具，默认只展示计划。
- 提供 OpenVINO GPU 基准工具；默认 ASR 仍使用 faster-whisper CPU/int8。

## 升级注意

这是包含部署模式变化的版本，请先阅读[迁移说明](../runtime-optimization.md)。
不要直接在旧配置上执行全量强制重建。

1. 保存原 Compose、环境配置及正在运行的镜像；数据库备份按既有策略执行。
2. 选择 compact 或 split。原本未使用的后台功能应继续关闭。
3. recorder、encoder、web 使用 `<版本>`，ASR 使用 `<版本>-ai`。
4. 等待正在运行的任务结束，先升级 ASR/Web，再迁移后台；录制器选择空闲窗口升级。
5. 停用 mongot 前先切换 MongoDB 配置并验证普通搜索，保留搜索数据。

ASR 检查点是新增的临时集合，不会改写已有转录。成功后清理，未完成检查点默认保留 7 天。
不能依靠程序回退恢复已删除的媒体或逆向迁移数据库。
