# IPTVPilot v0.1.0-rc.17

第二期落地转码与 AI 解耦、摘要可追溯和断流成果保留。
新增新闻/话题导航、转写文字检索和 SRT/WebVTT 字幕导出。
采集完成后即可转码，ASR 继续读取已固定的媒体来源；文件读取租约保护尚在使用的原文件。

摘要要点可查看逐字原文并跳转录像。人工校正保留原始识别与版本，未改动笔记复用，
新正式摘要默认不重新推送。无法核对的引用明确显示未定位，不使用模型推测的时间。

可用断流片段独立保存，保留音轨和已完成草稿，页面显示估算缺口，最终摘要标注不完整。
源页面展示最近实际录制的稳定性数据，原有锁定与优先级设置不被改写。

本版本也修复了隔离真实媒体验收中发现的预编译 FFmpeg gconv 路径兼容问题。

## 升级范围

定向升级 recorder、encoder、ASR、background、web，先排空旧读者再解除维护暂停。
沿用现有媒体和 ASR 镜像变体，无需新增服务或更新数据库、iptv-api。
配置与回退备份仅保留在部署端，不上传公开仓库。

详细行为、限制与页面验收清单见[第二期说明](../analysis-phase2.md)。
