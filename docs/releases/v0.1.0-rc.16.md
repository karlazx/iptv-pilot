# IPTVPilot v0.1.0-rc.16

本版本落地录制期间的实时文字、预览摘要与增量正式分析。
录制和 AI 并行执行，节目结束后汇总已经处理的内容，减少整场串行等待。

短窗口识别用于草稿，正式窗口保持原有 300 秒上下文；两个通道的笔记严格分离，
短窗的错字不会被直接作为正式摘要输入。只有正式摘要发布成功才允许推送。
录制音频从本地 TS 提取，不增加直播上游连接；失败时优先保留录像并回到录后转写。

## 升级

定向更新 recorder、ASR、web 和 background。split 模式对应更新 llm、push 等相关服务。
encoder、MongoDB、iptv-api 无需更新。保留旧版定制基础 Compose 的部署可叠加
`docker-compose.live-analysis.yml`，recorder 和 ASR 必须共享音频缓存目录。
升级前等待活动任务结束并保存配置与回退镜像。

## 使用和开销

订阅和手工录制增加「录制时转写」选项，录制详情自动显示实时草稿、独立处理状态、
落后采集时长和实际设备。默认每 180 秒归纳预览，只有启用 ASR 的录制任务参与。
双通道增加推理量和 LLM 调用；CPU 回退、多路任务或历史积压会增加延迟。
可关闭单个订阅的实时分析，或将 `LIVE_ASR_ENABLED=0` 恢复录后处理。

实现、配置、恢复与可重复验收命令见[实时分析指南](../live-analysis.md)。
